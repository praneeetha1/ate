# TimeToCook 🍳

A cozy, vintage-style recipe catalog web app.

- Browse 80 recipes across 10 categories
- Search by ingredients you already have
- Save favorites
- Click any recipe card to see ingredients (with checkboxes) and step-by-step instructions

**Built with:** plain HTML, CSS, and JavaScript — no frameworks, no backend.

**Live site:** https://praneeetha1.github.io/ate
